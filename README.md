# 📊 Sales Analytics Dashboard using Microsoft Fabric & Power BI

## 📌 Project Overview

This project is an end-to-end **Sales Analytics Dashboard** developed using **Microsoft Fabric** and **Power BI** to transform raw sales data into actionable business insights.
The solution follows a modern analytics workflow where sales data is **ingested, transformed, modelled, and visualized** using Microsoft Fabric before being consumed in an interactive Power BI report. By leveraging **OneLake**, a **Semantic Model**, and Power BI, the dashboard provides a centralized and scalable analytics solution for business reporting.
The dashboard enables users to monitor key sales metrics, evaluate regional performance, analyse product categories, track monthly revenue trends, and identify high-value customers through interactive visualizations.

---

##  Features

- Built using **Microsoft Fabric** with a centralized **Semantic Model**
- Designed an optimized **Star Schema** data model using Fact and Dimension tables
- Created DAX measures and KPIs for:
  - Total Revenue
  - Total Orders
  - Total Quantity Sold
  - Average Revenue per Order
  - Average Quantity per Order
- Interactive slicers for:
  - Date
  - Month
  - Quarter
  - Year
- Monthly Revenue Trend Analysis
- Revenue Analysis by Region
- Orders Analysis by Region
- Revenue by Product Category
- Quantity Sold by Product Category
- Top 10 Customers by Revenue
- Executive dashboard with KPI cards, charts, and interactive visuals
- Published to **Microsoft Fabric / Power BI Service**
